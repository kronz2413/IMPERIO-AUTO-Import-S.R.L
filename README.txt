# Imperio Auto Import S.R.L.

Página web completa, responsive e interactiva.

## Archivos
- `index.html` — estructura de la página.
- `styles.css` — diseño, responsive y tarjetas.
- `script.js` — menú móvil, filtros de vehículos, formulario y botón volver arriba.

## Cómo usar
Abre `index.html` en Chrome, Safari o cualquier navegador.

## Personalización
Reemplaza:
- `(809) XXX-XXXX`
- `info@imperioauto.com`
- `@ImperioAutoRD`
- Las imágenes remotas de Unsplash por fotografías reales del inventario.
- Los datos de vehículos y precios cuando cambien.

El formulario actualmente muestra una confirmación en pantalla; todavía no envía los datos a una base de datos ni a WhatsApp.
